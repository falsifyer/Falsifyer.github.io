# Security policy

## Reporting a vulnerability

Report suspected vulnerabilities in this site or in the code behind it to
[hola@martineliseo.es](mailto:hola@martineliseo.es). Please do not open a public
issue for a security problem.

Include, where you can: what you found, the URL or command that reproduces it, and
the impact you believe it has.

## Scope

- This repository and the site it publishes (`https://martineliseo.es`).
- The reference implementation in
  [`Falsifyer/Defensible-CTI`](https://github.com/Falsifyer/Defensible-CTI), which
  keeps its own policy.

Out of scope: findings that require access to an account, social engineering,
denial of service, and reports produced only by an automated scanner without a
reproduction.

## What to expect

This is a single-author project, not a product with a support contract. Reports are
read and answered on a best-effort basis; there is no bounty and no SLA. A confirmed
issue is fixed in the repository and noted in the changelog when it affects
published content.
